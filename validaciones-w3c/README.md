## Validación del sitio web

Antes de la publicación del portafolio, se realizó una validación completa del HTML y CSS, asegurando el cumplimiento de los estándares de calidad web.

### Validación HTML5

El archivo `index.html` fue validado utilizando la herramienta oficial del W3C:

- Se comprobó la correcta estructura semántica del documento.
- Se verificaron etiquetas bien anidadas y atributos válidos.
- Se aseguró la compatibilidad con el estándar **HTML5**.

 **Resultado**: Sin errores de marcado.

Herramienta utilizada: [W3C Markup Validation Service](https://validator.w3.org/)

---

###  Validación CSS

El archivo `style.min.css` fue validado para confirmar:

- Reglas CSS compatibles con navegadores actuales.
- Ausencia de errores de sintaxis.
- Uso correcto de variables CSS (`--primary-color`, `--text-color`, etc.).

 **Resultado**: Código CSS válido según los estándares del W3C.

Herramienta utilizada: [W3C CSS Validator](https://jigsaw.w3.org/css-validator/)

---

###  Accesibilidad

El sitio está diseñado teniendo en cuenta buenas prácticas de accesibilidad:

- Navegación por teclado con foco visible (`:focus-visible`).
- Contrastes adecuados entre fondo y texto.
- Jerarquía correcta de encabezados y uso responsable de `aria-labelledby`.

---

 **Nota**: La validación garantiza compatibilidad técnica y refleja buenas prácticas de desarrollo web profesional.
